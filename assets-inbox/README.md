# Папка приёмки картинок

Сюда кладём экспорт из Figma для галереи «Вдохновение», затем:

    php tools/import-gallery.php

Скрипт зальёт всё в медиабиблиотеку и разложит по плиткам галереи
по кругу, в алфавитном порядке имён файлов. Имя файла становится
названием в медиабиблиотеке и атрибутом alt — называйте осмысленно
(`gory-tuman.jpg`, `mramor-seryy.jpg`, `botanika-oliva.jpg`).

Сами картинки в репозиторий не попадают, только этот файл.
